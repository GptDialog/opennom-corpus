# Схема корпуса OpenNom

Параллельный корпус **bur → rus → eng**, собираемый носителями. Кодировка строго **UTF-8** (буквы Һ Ү Ө Э нельзя терять). Все текстовые таблицы лежат в `corpus/text/*.csv` и имеют одинаковый набор колонок. Аудио описывается в `corpus/audio/manifest.csv`.

## Текстовые таблицы (`corpus/text/*.csv`)

| Колонка | Обязательна | Описание |
|---|---|---|
| `id` | **да** | Уникальный идентификатор записи во всём корпусе (напр. `fam-0001`). Уникальность проверяется по всем файлам сразу. |
| `bur` | **да** | Бурятский текст (кириллица + Һ Ү Ө). **Заполняет только носитель.** ИИ-генерация запрещена. Латиница в этом поле — ошибка контаминации. |
| `rus` | **да** | Русский перевод. |
| `literal_rus` | нет | Буквальный (подстрочный) русский разбор. Обязателен по смыслу для `idiom`/`proverb`/`yorol`, где образ теряется при обычном переводе. |
| `eng` | нет | Английский перевод. |
| `type` | **да** | Тип единицы. Enum (см. ниже). |
| `register` | нет | Регистр речи. Enum (см. ниже). |
| `dialect` | нет | Диалект (напр. `khori`, `bargut`, `ekhirit`, `tsongol`). Свободное поле, рекомендуется придерживаться известных названий. |
| `source` | нет | Источник: словарь, сборник, «записано от носителя», имя информанта/полевой записи. |
| `usage_note` | нет | Заметка об употреблении (контекст, ограничения, коннотация). |
| `theme` | **да** | Культурная тема урока (напр. `family`, `greetings`, `rituals`, `proverbs`). Свободное поле. |
| `lesson` | нет | Идентификатор урока внутри темы (напр. `family-01`). |
| `level` | нет | Уровень CEFR-подобный: `A1`/`A2`/`B1`/`B2`/`C1`/`C2`. |
| `order` | нет | Порядок единицы внутри урока (целое число). |
| `audio_id` | нет | Ссылка на запись в `audio/manifest.csv`. Если не пусто — должна существовать в манифесте, а файл — в `audio/files/`. |
| `translator` | нет | Кто перевёл/внёс. |
| `verified_by` | нет | Кто из носителей/экспертов выверил. Заполняется при переходе в `verified`. |
| `status` | **да** | Жизненный цикл записи. Enum (см. ниже). |
| `date_added` | нет | Дата добавления `YYYY-MM-DD`. |
| `notes` | нет | Свободные заметки (правки, открытые вопросы, пометки PLACEHOLDER). |

## Enum-значения

### `type`
| Значение | Смысл |
|---|---|
| `word` | Одно слово. |
| `phrase` | Словосочетание из 2+ слов. |
| `sentence` | Законченное предложение. |
| `idiom` | Идиома (переносное значение; заполняй `literal_rus`). |
| `proverb` | Пословица/поговорка. |
| `yorol` | Йорол — традиционное благопожелание. |
| `text` | Связный текст длиннее предложения. |

### `register`
| Значение | Смысл |
|---|---|
| `neutral` | Нейтральный. |
| `colloquial` | Разговорный. |
| `formal` | Книжный/официальный. |
| `ritual` | Обрядовый (йоролы, обращения, ритуальная речь). |
| `archaic` | Устаревший/архаичный. |

### `status`
| Значение | Смысл |
|---|---|
| `draft` | Черновик / плейсхолдер, бурятское поле ещё не заполнено носителем. |
| `translated` | Переведено, ждёт выверки носителем. |
| `verified` | Выверено носителем (`verified_by` заполнен). Только такие строки идут в публичные продукты. |
| `published` | Опубликовано в релизе/датасете. |

## Аудио (`corpus/audio/manifest.csv`)

| Колонка | Описание |
|---|---|
| `audio_id` | Уникальный id записи (напр. `aud-0001`), на него ссылается `audio_id` в тексте. |
| `file` | Путь к файлу относительно `corpus/audio/` (напр. `files/aud-0001.mp3`). |
| `speaker` | Идентификатор диктора (анонимизированный при необходимости). |
| `dialect` | Диалект записи. |
| `theme` | Тема. |
| `source` | Источник/обстоятельства записи. |
| `consent` | Наличие согласия диктора: `yes`/`no`. |

## Совместимость

CSV грузятся в `pandas.read_csv(..., encoding="utf-8")` и в HuggingFace `datasets` без преобразований. Не меняй порядок/имена колонок без обновления `schema.md`, `validate.py` и `counts.py`.
